# Rem Gose — Hỗ trợ dịch game miễn phí

**Rem Gose dịch — AI của Dex Bill**

Rem Gose hỗ trợ dịch game **miễn phí** cho cộng đồng: dịch game Unity, Ren'Py, Godot, RPG Maker... sang tiếng Việt, dịch trực tiếp trong file game và đóng gói bản hoàn chỉnh để chơi ngay.

## Tiêu chuẩn bản dịch

- Dịch **100% text** trong game: thoại, giao diện, menu, mô tả, text ẩn trong plugin — không bỏ sót bề mặt nào
- Xưng hô đúng theo từng nhân vật, độ tuổi và mối quan hệ, nhất quán từ đầu đến cuối game
- Văn phong tự nhiên, đọc như game được viết gốc bằng tiếng Việt — không dịch máy, không dịch thô
- Không kiểm duyệt, không làm nhẹ nội dung: dịch đúng và đủ theo nguyên tác
- Ngắt dòng chuẩn theo khung thoại của từng engine
